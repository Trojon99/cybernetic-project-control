# Roadmap：按证据升级

## 0.1 alpha（本次）

交付自包含 Skill、原书追溯、四种领域 guidance、参考 adapter、合成示例、自动检查和公开开发测试。仅证明工程可运行。

## 下一道门：真实 Agent 小样本试验

同一模型比较无 Skill、memory-only、通用 PM、CPC；记录 prompt/hash、预算、工具权限、失败和人工介入。先覆盖科研测量、接口工程、软件交付，再增加未用于设计的真实项目。

若只增加报告长度却没有改善决策，删减/改写 Skill，不扩建 runtime。

## 再下一道门：跨 host 与消融

至少两种独立 host 与多个模型规模；单模型不同外壳不能代表跨模型泛化。去掉反馈时滞、状态观察、耦合、策略适应中的一项，看相应错误是否回升。

## 有实际需求后

选择一个现有后端做端到端 adapter，固定版本并验证断线、重试、权限与回读。没有需求或证据，不写 dashboard、数据库、调度器。

## 1.0 前

稳定语义、迁移工具、私有 held-out 评测、可复現宿主测试、明确退化行为、维护与发布流程。任何效果宣称附上逐任务数据和限制。
