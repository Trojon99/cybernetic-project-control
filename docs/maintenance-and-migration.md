# 维护与迁移

0.1 的状态/schema_version 固定为 `0.1`，包版本独立为 `0.1.0-alpha.1`。遇到未知 schema_version 必须拒绝自动写入，不做“尽力解释后覆盖”。

核心目标、验收描述、控制者身份、授权范围和预算是参考 adapter 的受保护配置，普通 `apply` 不修改它们。确需变更，由所有者在没有运行中的写入者时审查差异、保存 Git checkpoint、记录原因并升级目标版本；旧证据若不适用于新目标，应标 stale，不能继续支持当前主张。

核心文件过大或出现多人/跨机并发时，不通过给参考 adapter 添加分布式功能来解决；迁到已有后端。保留原记录的不可变副本，建立字段与引用映射，回读核对后才切换唯一权威位置。

失效的证据不删掉；普通更新只追加或标 stale/retracted。历史不会因为 Agent 觉得“没有用了”就被静默压缩。重复失败的规则必须保存适用条件，条件变化后允许重新试验。

`state.json` 是当前投影，receipts 是已经接受或待核对的 turn 记录，二者不构成第二个 task engine。孤立 receipt（不被 state.history 引用）从未获得状态提交资格。
