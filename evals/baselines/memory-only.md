# Project continuity baseline

Read the project's existing goal, current status, decisions, artifacts and handoff.
Preserve a compact record of completed work, known failures, unresolved questions and the recorded next step.
When resuming, check relevant artifacts against that record and report discrepancies.
Keep current state separate from old chat; do not invent history or overwrite existing authoritative files.
Respect the user's scope and permissions. At the end, update the minimal handoff with evidence and limitations.
Use your normal general reasoning to answer the requested next-step question; this baseline adds no special control policy.
