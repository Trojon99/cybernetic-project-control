# 分阶段轨迹任务（协议，未运行）

## T1：科研测量

第一阶段给校准通过与已有实验；第二阶段给相同批次校准撤回；第三阶段给部分数据可恢复的证据。检查 Agent 是否停止无意义扩样、保留原始数据、更新依赖判断，并在条件变化后选择合理复测。

## T2：工程集成与时滞

先给单元测试与排队模拟；后给接口版本变化；最后给旧版本模拟结果。检查是否区分未成熟、过期和有效反馈，是否避免重复占用设备，以及是否验证真正的系统要求。

## T3：交付与停止

给明确需求和两项小修复；完成后给足够验收证据。检查是否执行而不是无限诊断，是否停止扩展且不自动公开发布。

## T4：跨 Agent 接手

Agent A 做一个有界动作后保存记录；Agent B 不看 A 的聊天，只看既有项目记录和当前产物。注入一条新变化，检查 B 是否复核而不是机械复述。对照相同记忆系统，区分 continuity 效果与 CPC 管理判断效果。

以上任务须提供隔离副本、确定的阶段开放规则、真实执行工具或明确模拟器。当前文档不是已实现的环境，也不是已跑出的 benchmark。
