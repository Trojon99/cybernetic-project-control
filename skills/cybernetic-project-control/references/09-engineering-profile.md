# Engineering profile

适用于系统、硬件、机械、实验设备、工程集成等。观察需求、接口、设计假设、实施、验证环境、失效模式、依赖、资源与交付。

每条必须满足的需求应连到适用条件下的验证证据。组件测试不能自动覆盖系统集成；模拟测试不能不加说明地当实机安全证明。

检查耦合：接口版本、时序/单位、资源上限、热/电/机械约束、共同失效原因。不凭模块完成比例声称接近交付。

长提前期与验证排期可能比任务数量更重要。识别需要人批准的采购/设备运行，不由“时间紧”扩大权限。

涉及真实设备、部署、安全关键设计时，只在明确工程程序和授权范围内操作；本包不提供物理控制器或安全认证。

达到要求后交付；不能为了减少不确定性无限追加测量，也不能为了准时放弃未解决的安全约束。
