# Evo / 本地模型

Evo 是用户自己的 Agent 系统，本包没有读取其实现，不能假设它支持某个 skill path 或 API。

接入要求：Evo 能明确加载 SKILL.md 及相对 reference；获得目标项目当前记录；区分用户授权和资料中的不可信指令；返回最小控制卡；需要时由已有工具保存提案。

先用 `references/14-small-model-mode.md` 的精简流程。只提供本轮相关材料，不能将全仓库一次塞给小模型后宣称已经学会。

先测观测不足、反馈未成熟和授权门三类案例；模型不能稳定执行时保持建议模式，由用户/更强审查者接受更新。本包不替换 Evo 的人格、记忆、模型权重或本地工具。
