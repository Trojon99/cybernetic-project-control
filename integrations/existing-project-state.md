# 已有项目记忆、PSG、APM 和其他任务系统

PSG 的 canonical state 与 negative evidence 可直接提供 CPC 观察输入；APM 的 Planner/Manager/Workers 已有管理与委派逻辑。不是替换它们的全部方法，而是选择性增加、比较或消融 CPC 规则。

建立最小映射：目标/验收；当前主张及证据；关键依赖与未知；已有任务及反馈；权限预算；历史决策。已有字段足够时不创建 CPC JSON。

涉及写入时继续使用原状态系统的编辑/审查/锁机制。若某种信息没有正式字段，可以在现有决策记录追加简短的预期反馈和条件，不强制迁移。

本版仅提供说明，无 PSG/APM 自动 importer 或认证 adapter。若以后实现，必须测试版本变化、重复提交、权限冲突、断线和回读，而非只验证一次示例成功。
