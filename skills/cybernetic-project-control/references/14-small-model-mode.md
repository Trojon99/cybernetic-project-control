# 小模型与短上下文模式

不要预期读取长文件会自动提升推理能力。一次只载入 SKILL 的控制卡、当前关键状态和本轮需要的一个 profile/reference。

最小任务：
1. 引用三条以内与决策有关的事实。
2. 指出一个缺口或说明没有关键缺口。
3. 在执行/观察/等待/问人/停止中选一种，给出理由。
4. 写一个可检查结果和失败分支。
5. 保留权限与下一次恢复点。

若模型无法稳定遵守引用、权限和反馈规则，降级到“建议模式”，由人或更强审查者接受更新。不要让模型因为输出了格式正确的 JSON 就获得更高权限。

持续观察精简模式是否只会套模板而不会判断：给交付已足够明确的反例，正确行为是执行，不是永远建议更多研究。
